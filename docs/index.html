Explainable Semantic Code Search

Introduction

In this work, we aim to tackle two critical challenges in semantic code search: lack of explainability and poor generalizability. Traditional embedding-based code retrieval methods heavily depend on training data and often fail to generalize to new distributions, while their black-box nature limits user trust.

To address these issues, we introduce XSearch, an intrinsically explainable semantic code retriever designed to:

  • (i) Enhance Explainability: Identify and clearly align important concepts between queries and candidate code snippets, helping developers easily understand and verify retrieved results.
  • (ii) Boost Generalizability: By learning advanced concept extraction and alignment tasks, XSearch significantly improves retrieval performance on unseen (out-of-distribution) datasets without expanding training data or model size.

Dataset

  • Includes 925,362 query-code pairs in total.
  • Each pair is annotated with fine-grained concept-to-code alignments.
  • First explainability-oriented benchmark for semantic code search in the community.
